API Documentation

This page explains the available endpoints of the Docker Mini App.

Back to Mini App

Available Endpoints

GET /health

Check whether the Flask API service is running.

GET /db-check

Check whether the PostgreSQL database connection is successful.

GET /tasks

Get all tasks from the database.

POST /tasks

Create a new task.

{
  "title": "Learn Docker Compose"
}
PATCH /tasks/<id>/toggle

Toggle a task between done and not done.

DELETE /tasks/<id>

Delete a task by ID.

Example cURL Commands

Check API:

curl http://localhost:8080/health

Check database:

curl http://localhost:8080/db-check

Create task:

curl -X POST http://localhost:8080/tasks -H "Content-Type: application/json" -d "{\"title\":\"Learn Docker\"}"
