What this UI demonstrates

  • 1 Browser sends requests to Flask container.
  • 2 Flask reads DB settings from environment variables.
  • 3 API connects to PostgreSQL using Compose service name db.
  • 4 PostgreSQL data persists through Docker volume.
  • 5 UI updates dynamically using REST API endpoints.
